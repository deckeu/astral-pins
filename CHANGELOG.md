# Changelog

## 1.0.0 — 2026-11-25

First release.

- ROG Astral per-pin current/voltage reader over NVIDIA I2C (read-only)
- Watchdog user service: per-pin limits, imbalance and voltage-sag checks,
  KDE alert dialog with shutdown option, 30 s auto-shutdown on unanswered critical alerts
- Tray icon with live pin bars and a popup anchored to the icon (layer-shell)
- Optional per-pin history graphs
- Thermal Grizzly WireView Pro II support: second card, temperatures, PSU limit,
  fault flags, display screen switching
- Installer/uninstaller with optional udev rules
